# مغازه‌دار کوچولو — Android APK

نسخه اندرویدی بازی HTML با WebView ساخته می‌شود و انیمیشن‌ها، صدا و منطق بازی از فایل اصلی حفظ شده‌اند.

## ساخت APK با GitHub Actions
1. این ZIP را از حالت فشرده خارج کنید.
2. در GitHub یک مخزن جدید بسازید و تمام محتویات این پوشه را در ریشه مخزن بارگذاری کنید.
3. به زبانه **Actions** بروید و گردش‌کار **Build Android APK** را اجرا کنید (یا با push کردن کد به شاخه `main`/`master` خودکار اجرا می‌شود).
4. اجرای موفق را باز کنید؛ در بخش **Artifacts** فایل `Maghazedaar-Koochooloo-APK` را دانلود کنید.
5. ZIP آرتیفکت را باز کنید؛ فایل `app-debug.apk` همان APK قابل نصب است.

این خروجی debug برای نصب و آزمایش است؛ برای انتشار عمومی در فروشگاه‌ها باید نسخه release امضاشده ساخته شود.
